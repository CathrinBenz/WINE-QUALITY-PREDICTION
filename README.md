# Wine Quality Prediction 🍷

Machine Learning project to predict wine type using classification algorithms.

## 📌 Project Overview
This project uses machine learning techniques to classify wine type based on physicochemical properties.

## 🚀 Algorithms Used
- Logistic Regression
- KNN
- SVM
- Decision Tree
- Naive Bayes
- Random Forest

## 🔧 Techniques Used
- Label Encoding
- Missing Value Handling
- SMOTE
- Feature Selection
- StandardScaler
- Classification Metrics
- Hyperparameter Tuning

## 📊 Libraries Used
- Pandas
- NumPy
- Scikit-learn
- Seaborn
  

## 🎯 Result
Random Forest achieved high accuracy in wine type prediction.

## 📁 Dataset
Wine Quality Dataset
